# AGENTS.md

## What this is

Crew Station is a single static page: an isometric pixel-art space station on a 2D canvas whose robot crew act out one
JSON file (the "board"). Plain HTML, CSS and classic `<script>` files; no build, bundler, framework or backend. Private
repo, MIT licensed; the page only reads data. Nothing is released from here.

## Commands

- Check: `node tools/check.js` - green is `OK: <n> files, 17 scripts, 13 crew, 13 rooms.` and exit 0; needs only node.
- Check your own board: `node tools/check.js --board my-board.json`.
- Syntax of one script: `node --check js/fx.js`.
- Run: `python3 -m http.server 8000` from the repo root, then open http://localhost:8000/ (HTTP only; `file://` fails).
- Art scripts (`art-kit/tools/`): `python3 art-kit/tools/sheets.py check a|b|c FILE...`; the rest need Pillow and NumPy.
- Rendering, art alignment, depth sorting, animation and input cannot be verified without a browser; the check proves
  files and data agree, nothing more. Say so in a PR rather than claiming it looks right.

## Layout

| Path | What is there |
|---|---|
| `index.html`, `css/station.css` | the page and all styles |
| `js/` | 17 classic scripts, one global each; the load order is in `index.html` and the reference |
| `data/sample-board.json` | the default board, invented |
| `assets/` | rooms, objects, heroes, sprites, crew portraits, floors, placements, fonts |
| `tools/check.js` | the tree check |
| `art-kit/` | for making new art; the page loads nothing from it |
| `docs/AGENT-REFERENCE.md` | file map, board schema, hard-coded names, how to add crew, desks and rooms |
| `docs/ARCHITECTURE.md` | how the code runs: coordinates, boot, frame loop |

## Rules

- Branches `builder/<slug>` from `main`; never commit to `main` directly.
- Keep the page static: no build step, modules, dependencies, backend, or network calls beyond the board file.
- Truth rule: a figure's room, desk, blocked chain, "needs you" bubble and charging pad follow its board state;
  everything else (walking, chat, lamps, sparks) is ambient and claims nothing. Shuttle cargo comes only from real events.
- Run `node tools/check.js` before every push; it must exit 0.
- Keep the behaviors in the reference's "Behaviors that must hold": boot never hangs silently, the frame loop survives an
  error, and every baked canvas can be rebuilt (a new long-lived canvas joins `BAKERS`).
- A member, room or role key change must be made everywhere the reference's "Hard-coded names" lists.
- Replace art with a file of the same name and pixel size; hard-edged pixels, real transparency, no metadata.
- Only add art that may be released under MIT; an asset the page does not use fails the check.
- Keep `LICENSE`, `NOTICE.md` and `assets/fonts/OFL.txt` with the files.
- US English in code, comments, docs and commit messages.
- Commit messages end with `Co-Authored-By: <agent>`; never a claude.ai session link, `Claude-Session:` line or URL, in
  a commit or a PR body.
- A PR body is short: what changed, how it was checked, which browsers. Screenshots for anything visible.
- No secrets, tokens, phone numbers, addresses or people's names anywhere.

## Release

Not released: nothing is tagged or published from this repo. It is copied into a project as described in the reference.

## Do not touch

- `assets/` files by renaming or resizing: names and sizes are the contract with the code and the atlas JSON.
- `art-kit/templates/`: generated by `sheets.py template`; regenerate, do not hand-edit.
- `docs/AGENT-REFERENCE.md` is the one detail document; update it with the code, do not copy it into this file.
